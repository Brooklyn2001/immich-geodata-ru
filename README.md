# immich-geodata-ru — русская локализация обратного геокодирования Immich

Это проект, который добавляет **русскоязычную** поддержку функции обратного геокодирования в Immich. Он решает проблему того, что места съёмки фотографий распознаются только на английском / языке оригинала, а также оптимизирует результат.

- **Локализация мест**: для территорий России, Беларуси и Украины административные единицы (с 1-го по 4-й уровень) приводятся к нормализованному виду и заменяются на привычные русскоязычные названия.
- **Стандартизация адресов**: через API Nominatim адреса приводятся к четырём уровням — **1-й, 2-й, 3-й, 4-й административный уровень**, чтобы избежать нестандартных или малоизвестных названий, которые использует Immich по умолчанию. Точность выводимой гранулярности выбирается отдельно.
- **Автообновление**: репозиторий еженедельно подтягивает свежие данные геолокации и автоматически публикует обновления.

# Как использовать

### 1. Скачать данные

На странице [Release](https://github.com/Brooklyn2001/immich-geodata-ru/releases/latest) скачайте и распакуйте файлы `geodata.zip` и `i18n-iso-countries.zip`.

Релизы делятся на два типа:
- 🔄 [**Автообновляемая версия**](https://github.com/Brooklyn2001/immich-geodata-ru/releases/tag/auto-release): обновляется чаще, рекомендуется к использованию. Однако из-за возможных изменений источников данных иногда генерируемые файлы могут быть непригодными. При проблемах переключайтесь на ручную версию и создавайте issue.
- 🛠️ [**Ручная версия**](https://github.com/Brooklyn2001/immich-geodata-ru/releases): более стабильна, подходит как запасной вариант.

Версии с суффиксом `_full` содержат больше данных — точнее распознают местоположение на границах, но могут снижать скорость геокодирования.

### 2. Настроить монтирование контейнера Docker

Отредактируйте свой `docker-compose.yaml`, добавив следующие тома (или замените целевые папки под свой способ развёртывания):

Если используется официальный образ `immich-app/immich-server`, пути такие:

```yaml
# immich версии >= 1.136.0
volumes:
  - ./geodata:/build/geodata
  - ./i18n-iso-countries/langs:/usr/src/app/server/node_modules/i18n-iso-countries/langs

# immich версии < 1.136.0 (не включая)
volumes:
  - ./geodata:/build/geodata
  - ./i18n-iso-countries/langs:/usr/src/app/node_modules/i18n-iso-countries/langs
```

Если используется образ `imagegenius/immich`, пути такие (спасибо huazhaozhe [#18](https://github.com/ZingLix/immich-geodata-cn/discussions/18)):

```
volumes:
  - ./geodata:/app/immich/data/geodata
  - ./i18n-iso-countries/langs:/app/immich/server/node_modules/i18n-iso-countries/langs
```

### 3. Перезапустить Immich

Выполните `docker compose down && docker compose up`, чтобы перезапустить Immich.
- Если в логах запуска появится примерно `10000 geodata records imported` — значит geodata успешно обновлён.
- Если такого лога нет, попробуйте изменить дату в файле `geodata/geodata-date.txt` на текущее время: Immich обновляет данные только если дата файла новее, чем время последней загрузки.
  ![](./image/importlog.jpg)

### 4. Обновить метаданные

> **Внимание**: этот шаг нужен только при первом использовании геоданных из этого проекта — он обновляет позиции всех существующих фотографий. Для новых фотографий повторять не нужно.

Зайдите в «Администрирование — Задачи», нажмите «Извлечь метаданные» → «Все», чтобы запустить обновление позиций всех фото. После завершения у всех фотографий позиция будет отображаться на русском и поддерживать поиск по-русски.

# Как обновляться

Просто заново скачайте файлы со страницы последнего Release, замените старые и перезапустите Immich.

Для быстрого обновления можно использовать скрипт автоматического скачивания и замены:

```bash
# cd geodata   — выполнять в каталоге geodata

# Скачать скрипт
curl -o update.sh https://raw.githubusercontent.com/Brooklyn2001/immich-geodata-ru/refs/heads/main/geodata/update.sh

# Запустить скрипт обновления; параметр — нужная версия, например geodata_admin_2
bash update.sh geodata_admin_2
```

После обновления нужно перезапустить Immich, чтобы данные перезагрузились. Чтобы перезапуск происходил автоматически, можно добавить в конце скрипта команду вроде `docker restart immich_server`, либо запускать обновление и перезапуск вместе по расписанию, например:

```bash
5 5 * * 6 bash /immich_data/geodata/update.sh && docker restart immich_server
```
