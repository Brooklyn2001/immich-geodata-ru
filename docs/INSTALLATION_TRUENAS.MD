# Инструкция по добавлению русскоязычного обратного геокодирования в Immich на TrueNAS

**🇷🇺 Русский** | [🇬🇧 English](INSTALLATION_TRUENAS_EN.MD)

Данная инструкция предполагает, что Immich уже установлен и работает на вашем TrueNAS (SCALE). Мы добавим поддержку русскоязычных названий мест с помощью проекта `immich-geodata-ru`.

## Что изменится

После выполнения инструкции места съёмки фотографий в Immich будут отображаться на русском языке (например, «Москва, Россия» вместо «Moscow, Russian Federation»), а также появится возможность поиска фотографий по русским географическим названиям.

## Шаг 1: Скачивание данных

1. Перейдите на страницу релизов проекта:  
   [https://github.com/Brooklyn2001/immich-geodata-ru/releases/latest](https://github.com/Brooklyn2001/immich-geodata-ru/releases/latest)

2. Скачайте два архива:
   - `geodata.zip` — данные о городах и административных единицах
   - `i18n-iso-countries.zip` — данные о странах на русском языке

   > **Важно:** Выбирайте файл с нужной вам точностью. Суффиксы `_admin_2`, `_admin_3`, `_admin_4` и их комбинации определяют уровень детализации (область, район, город). Файлы с `_full` содержат больше данных, но работают медленнее. Если не уверены — начните с обычного `geodata.zip`.

3. Распакуйте оба архива в отдельную папку на вашем TrueNAS. Рекомендуется создать её внутри датасета, который используется для хранения конфигурации Immich. Например:

   ```bash
   mkdir -p /mnt/ваш-пул/immich/immich-geodata-ru/geodata
   mkdir -p /mnt/ваш-пул/immich/immich-geodata-ru/i18n-iso-countries/langs
   ```

   Распакуйте `geodata.zip` в папку `geodata`, а `i18n-iso-countries.zip` — в `i18n-iso-countries` (внутри должна появиться подпапка `langs`).

   В итоге структура должна выглядеть так:

   ```
   /mnt/ваш-пул/immich/immich-geodata-ru/
   ├── geodata/
   │   ├── cities500.txt
   │   ├── admin1CodesASCII.txt
   │   ├── ... (другие файлы)
   │   └── geodata-date.txt
   └── i18n-iso-countries/
       └── langs/
           ├── ru.json
           └── ... (другие языки)
   ```

## Шаг 2: Добавление монтирования в контейнер Immich

Способ зависит от того, как именно у вас развёрнут Immich на TrueNAS.

### Вариант A: Immich установлен через Custom App (Docker Compose)

Если вы устанавливали Immich через **Custom App** с использованием YAML (как описано в официальной документации TrueNAS), найдите файл `docker-compose.yml` вашего приложения. Обычно он расположен в `/mnt/ваш-пул/apps/immich/docker-compose.yml` или в аналогичном месте.

Откройте файл и добавьте в секцию `volumes` сервиса `immich-server` две строки. Пути слева — это ваши локальные папки, справа — целевые пути внутри контейнера. Для официального образа `immich-app/immich-server` версии **1.136.0 и выше** используйте такие целевые пути:

```yaml
services:
  immich-server:
    # ... (остальная конфигурация)
    volumes:
      # ... (существующие тома)
      - /mnt/ваш-пул/immich/immich-geodata-ru/geodata:/build/geodata
      - /mnt/ваш-пул/immich/immich-geodata-ru/i18n-iso-countries/langs:/usr/src/app/server/node_modules/i18n-iso-countries/langs
```

> **Примечание:** Если вы используете образ `imagegenius/immich` (часто встречается в community-приложениях TrueNAS), пути будут другими:
> ```yaml
> - /mnt/ваш-пул/immich/immich-geodata-ru/geodata:/app/immich/data/geodata
> - /mnt/ваш-пул/immich/immich-geodata-ru/i18n-iso-countries/langs:/app/immich/server/node_modules/i18n-iso-countries/langs
> ```

### Вариант B: Immich установлен через встроенное приложение TrueNAS

Если Immich был установлен как обычное приложение через каталог **Apps** в веб-интерфейсе TrueNAS, добавление дополнительных томов может быть невозможно без пересоздания приложения. В таком случае:

1. Сделайте резервную копию конфигурации Immich и базы данных.
2. Удалите приложение Immich (данные на датасетах сохранятся).
3. Установите Immich заново через **Custom App** → **Install via YAML**, добавив необходимые тома, как описано в варианте A.

> Это единственный надёжный способ добавить произвольные монтирования к приложению, установленному через стандартный установщик TrueNAS.

## Шаг 3: Перезапуск Immich

После изменения `docker-compose.yml` перезапустите контейнеры Immich:

```bash
cd /mnt/ваш-пул/apps/immich
docker compose down
docker compose up -d
```

Если вы используете Custom App через веб-интерфейс TrueNAS, просто перезапустите приложение через кнопку **Restart** в интерфейсе Apps.

## Шаг 4: Проверка импорта геоданных

После запуска проверьте логи контейнера `immich-server`:

```bash
docker logs immich-server 2>&1 | grep -i geodata
```

При успешном импорте вы должны увидеть сообщение, похожее на:

```
10000 geodata records imported
```

Если такого сообщения нет, проблема чаще всего в том, что Immich не считает данные «новыми». Immich обновляет геоданные только если дата в файле `geodata-date.txt` новее, чем время последнего импорта. Откройте файл `/mnt/ваш-пул/immich/immich-geodata-ru/geodata/geodata-date.txt` и измените дату на текущую (или любую будущую), затем перезапустите контейнер.

## Шаг 5: Обновление метаданных существующих фотографий

> **Внимание:** Этот шаг нужен только при первом использовании геоданных из проекта. Для новых фотографий повторять не нужно.

1. Войдите в веб-интерфейс Immich как администратор.
2. Перейдите в **Администрирование** → **Задачи**.
3. Найдите задачу **«Извлечь метаданные»** и нажмите **«Все»**.
4. Дождитесь завершения задачи. В зависимости от размера библиотеки это может занять продолжительное время.

После завершения у всех фотографий с геотегами позиции отобразятся на русском языке, и поиск по русским названиям начнёт работать.

## Обновление данных

Репозиторий `immich-geodata-ru` обновляется еженедельно. Для получения свежих данных:

1. Скачайте новые архивы со страницы релизов.
2. Замените содержимое папок `geodata` и `i18n-iso-countries/langs` новыми файлами.
3. Перезапустите Immich (`docker compose down && docker compose up -d`).

В репозитории также есть скрипт `update.sh` для автоматического обновления, который можно запускать по расписанию через встроенный планировщик задач TrueNAS.

## Возможные проблемы

| Проблема | Решение |
|---|---|
| В логах нет сообщения об импорте geodata | Измените дату в `geodata-date.txt` на текущую и перезапустите контейнер |
| Русские названия не отображаются после обновления метаданных | Убедитесь, что тома смонтированы правильно (проверьте `docker inspect immich-server` и пути внутри контейнера) |
| Контейнер не запускается после добавления томов | Проверьте права доступа к папкам на хосте — они должны быть читаемы пользователем, от которого работает Immich |
| Названия частично на английском | Выберите файл `geodata` с более высокой точностью (например, `geodata_admin_2_admin_3_admin_4.zip`) |
